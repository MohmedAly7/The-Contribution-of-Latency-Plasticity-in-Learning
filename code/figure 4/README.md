# Figure 4 — Two-Neuron Network with Reciprocal Coupling

> **Caption:** **a,** For specific values of $l_{12}$ and $l_{21}$, the two neurons mutually entrain one another, producing polychronous firing at a frequency exceeding their respective initial firing rates. **b,** Following training, the spiking activity of the two neurons exhibits phase-locked dynamics, as depicted by the solid blue and red arrows.

---

## Overview

This folder contains the C++ simulation code that generates the data files for **Figure 4a** and **Figure 4b**.

The simulation models a two-neuron leaky integrate-and-fire (LIF) network with reciprocal synaptic coupling and spike-timing-dependent plasticity (STDP). The two neurons start with different intrinsic firing periods and, through learning, mutually entrain into a common polychronous rhythm — converging to a phase-locked state with a firing frequency higher than either neuron's initial rate.

## Files

| File | Description |
|------|-------------|
| `figure_4_a&b.cpp` | C++ source — runs the LIF simulation and writes both output files |
| `figure4a.neuron` | Binary output — spike/event stream used to plot **panel a** (firing period vs. time) |
| `figure4b.neuron` | Binary output — phase data used to plot **panel b** (circle phase diagrams) |

> The `.neuron` files are generated by compiling and running the C++ source. They are binary files with a custom format described below.

---

## How to Build and Run

### Requirements
- A C++ compiler supporting C++11 or later (`g++`)
- No external libraries required

### Compile
```bash
g++ -O2 -o figure4 "figure_4_a&b.cpp"
```

### Run
```bash
./figure4
```

The simulation prints progress every 200,000 events and reports the final simulation time and random seed. On completion it writes:
- `figure4a.neuron`
- `figure4b.neuron`

## Output File Format

Both output files share the same binary layout.

### Header (4 bytes)
| Bytes | Type | Value |
|-------|------|-------|
| 0–3 | `int32` | Number of neurons `cc` (= 2) |

### `figure4a.neuron` — Event stream
Each record is **24 bytes**:

| Bytes | Type | Field | Notes |
|-------|------|-------|-------|
| 0–7   | `double` | Simulation time `t` (ms) | Absolute time of the event |
| 8–11  | `int32`  | Pre-synaptic neuron index `i` (0-based) | |
| 12–15 | `int32`  | Post-synaptic neuron index `j` (0-based) | |
| 16–23 | `double` | Value | `1.5` for a firing event (`i == j`); `−w[j][i] / maxW` for a synaptic reception |

### `figure4b.neuron` — Phase (circle) data
Each record is **4 + cc × 8 = 20 bytes**:

| Bytes | Type | Field | Notes |
|-------|------|-------|-------|
| 0–3   | `int32`  | Firing neuron index `i` (0-based) | |
| 4–11  | `double` | Time since last self-spike of neuron 0 seen at `i` | Elapsed phase |
| 12–19 | `double` | Time since last spike of neuron 1 seen at `i` | `−1` if no such spike is in history |

## Model Description

### Network
- **2 LIF neurons** (`cc = 2`, `nActive = 2`) with reciprocal excitatory synapses.
- Each neuron is driven by a constant suprathreshold input current, giving different intrinsic periods:
  - Neuron 1 (`n1`): faster intrinsic rhythm (lower firing period, ~30 ms, blue)
  - Neuron 2 (`n2`): slower intrinsic rhythm (higher firing period, ~33 ms, orange/red)

### LIF Dynamics
The membrane voltage evolves as an RC circuit:

$$V(t) = V_{ss} + (V_0 - V_{ss})\, e^{-(t - t_0)/\tau}$$

where $V_{ss} = I_{input} \cdot R_M$ is the steady-state voltage, $\tau = 20$ ms is the membrane time constant, and $R_M = 10\,\text{M}\Omega$ is the membrane resistance. A spike is emitted when $V$ reaches the threshold $V_{thr} = 1.0$.

### Plasticity (STDP)
Weights are updated at each spike according to nearest-neighbour STDP:

- **Potentiation** (pre before post): $\Delta w = \eta_w \cdot e^{-\Delta t / T_2}$
- **Depression** (pre after post): $\Delta w = -\eta_w \cdot e^{-\Delta t / T_2}$

where $T_2 = 10$ ms and $\eta_w = 5 \times 10^{-3}$. Weights are bounded in $[0,\, w_{max}]$ with $w_{max} = 0.05$.

### Key Parameters

| Parameter | Symbol | Value | Description |
|-----------|--------|-------|-------------|
| Firing threshold | $V_{thr}$ | 1.0 | Normalised voltage |
| Membrane time constant | $\tau$ | 20 ms | Decay time |
| Membrane resistance | $R_M$ | 10 MΩ | RC model |
| STDP time constant | $T_2$ | 10 ms | |
| Weight learning rate | $\eta_w$ | 5×10⁻³ | |
| Max synaptic weight | $w_{max}$ | 0.05 | |
| Chosen latency $l_{12}$ | `L[0][1]` | 9.6723 ms | Spike travel time n2→n1 |
| Chosen latency $l_{21}$ | `L[1][0]` | 19.0089 ms | Spike travel time n1→n2 |

## Reproducing Figure 4

### Panel a — Firing Period vs. Time
Read `figure4a.neuron`, extract firing events (`i == j`) per neuron, compute inter-spike intervals (Firing period), and plot Firing period vs. time. The MATLAB viewer scripts in the repository root (`Firing period_viewer.m`) can be used directly.

### Panel b — Phase Circle Diagrams
Read `figure4b.neuron` and plot each event as an arrow on a unit circle at angle $\theta = 2\pi \cdot t_{other} / T_{self}$. The MATLAB viewer (`circle_viewer.m`) in the repository root handles this automatically.
